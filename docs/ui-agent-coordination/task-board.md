# UI Task Board

## 1. Admin Console

Create a first-screen dashboard that clearly shows the system has changed:

- module status tiles with counts where cheap to query
- launch buttons for Seller Portal, Admin Review, Reference Console, AI Advisor
- quick API checks as visible buttons
- warning badges for demo-placeholder features like TTS/PMTiles/Gemini

## 2. Seller Portal

Create visible seller/owner UI:

- owner registration page
- seller dashboard
- seller POI submission form
- seller list of owned POIs with status Pending/Approved/Rejected
- seller edit page for pending/inactive POIs

## 3. Admin Review

Create visible admin UI for seller submissions:

- pending POI queue
- approve/reject buttons
- owner/tenant details
- status badges
- link back to normal POI admin

## 4. Workflow Console

Create visible controls for reference workflows:

- localization warmup form by language
- hotset/on-demand demo controls
- audio TTS text input and generated URL/result
- maps offline manifest viewer

## 5. AI Advisor UI

Create visible AI enhancement workflow:

- form for name, category, address, price range, description
- result card with provider, remaining usage, enhanced content
- copy/apply text affordance where easy

## 6. Mobile Demo UI

Create visible MAUI evidence:

- startup sync status
- selected language
- nearby/hotset status
- offline cache status
- narration fallback status
- manual refresh/test controls

## 7. Demo Polish Docs

Document what changed by role:

- User App
- Seller/Owner
- Admin
- Backend/API
- Demo limitations

## 8. UI Verification

After merge:

- build CMS
- build mobile
- run or manually smoke CMS UI pages
- document screenshots/checklist
